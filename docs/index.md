# BizNote

BizNote is an iOS and iPadOS business note app for creating work logs, meeting minutes, event notes, custom note templates, and business card records.

## Core Features

- Create business notes by type
- Manage meeting minutes, work logs, event notes, and custom templates
- Scan business cards and extract text on device
- Save business card information and optionally add it to Contacts
- Export supported data through the system share sheet

## Privacy

BizNote does not require login, does not include advertising SDKs, and does not track users.

User data is stored on the device. If iCloud sync is enabled, data may sync through the user's personal iCloud account using Apple's CloudKit service.

Release Notes

📱 현재 버전Latest 2.0 iOS 17.0+ iPhone · iPad
2.0LATEST
NEW
  • 행사 모드 추가: 명함 스캔 또는 직접 입력으로 방문객 정보를 수집하고 관심분야·자료 요청 여부를 기록
  • 행사 모드 수집 화면에서 홍보 영상 반복 재생
  • ⓘ 아이콘을 눌러 PIN 또는 생체인증으로 담당자 화면(방문객 목록, 설정) 진입
  • 명함·방문객 목록 PDF 내보내기 (1건당 1페이지)
  • 방문객 데이터 선택 초기화 (행사별 또는 전체, 삭제 전 재확인) — 행사 정보와 일반 노트·명함은 유지
  • New Event Mode: collect visitors by scanning cards or manual entry, and record interests and material requests
  • Looping promo video on the Event Mode collection screen
  • Tap ⓘ and authenticate with PIN or biometrics to open staff screens (visitor list, settings)
  • PDF export of cards and visitor lists, one page per entry
  • Selective reset of visitor data (per event or all, with confirmation) — event info and regular notes/cards are unaffected
IMPROVED
  • 방문객 목록·상세에서 관심분야와 자료 요청 상태를 아이콘과 색상으로 표시
  • 명함 OCR 정확도 향상: 어둡거나 반사가 심한 명함 보정, 인식 언어 우선 재인식, 전화번호·이메일 등 보정 결과 병합
  • 스캔 결과에서 인식 신뢰도가 낮은 항목 표시
  • Interests and request status shown with icons and colors in visitor list and detail
  • Better card OCR: enhancement for dark or glare-heavy cards, re-recognition prioritizing the detected language, merged results for phone numbers and emails
  • Low-confidence fields are flagged on the scan result
1.25
FIXED
  • 모든 노트 리스트에서 작성일이 아닌 오늘 날짜가 표시되던 문제
  • 한국어 화면에서 "Recent"가 "최근"으로 표시되도록 수정
  • Note lists showing today's date instead of the creation date
  • "Recent" now shows as "최근" in the Korean UI
IMPROVED
  • 회의록 안건·논의·결정사항을 항목 단위로 입력·수정하고 위아래로 재정렬
  • 온라인 미팅 링크를 클릭 가능한 링크로 표시 (최근 위치 목록에는 저장 안 됨)
  • 행사노트 입력 화면 정리: 테두리 제거, 구분선 정리, 폰트 색상·크기·정렬 통일
  • 주요 아이콘 버튼과 메뉴의 접근성 라벨 개선
  • Agenda, discussion and decision items in minutes are editable per item and reorderable
  • Online meeting links are clickable and excluded from the recent locations list
  • Cleaner event-note inputs: no borders, tidier dividers, consistent font color, size and alignment
  • Improved accessibility labels for key icon buttons and menus
1.24
FIXED
  • 명함 스캔 후 인식 정보가 저장되지 않거나 목록에 나타나지 않는 문제
  • iPhone에서 명함 이미지가 저장되지 않는 문제
  • 3열 레이아웃에서 상세 영역이 잘못 "노트 없음"으로 표시되는 문제
  • Scanned card data not being saved or listed
  • Card images not saving on iPhone
  • Detail pane wrongly showing "No notes" in the 3-column layout
IMPROVED
  • 여러 장 연속 스캔 시 명함별 OCR·파싱 결과를 정확히 반영
  • 한국어·영어 명함 인식 및 파싱 규칙 보강
  • iPad 명함 관리: 세로 2열, 가로 3열(사이드바·목록·상세) 지원, 화면 회전 시 선택 메뉴 유지
  • Accurate per-card OCR/parsing results when scanning several cards in a row
  • Stronger Korean and English card recognition and parsing
  • iPad card management: 2 columns in portrait, 3 columns in landscape; selected menu persists on rotation

이전 버전의 변경 내역은 GitHub 저장소의 릴리스 노트에서 확인할 수 있어요.
